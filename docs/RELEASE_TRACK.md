# Incremental AER release track

## Track A
Core .NET reference, adapters, specification and governance.

## Track B
CLI, conformance suite, comparison matrix, MCP/ASP.NET integration and benchmark tooling.

## Track C
Independent Python, TypeScript and Go implementations, frozen AER-B vectors, tokenizer-aware AI benchmarks and package release automation.

## Track D
Advanced parity: full table/schema/patch/stream implementations in each language, property/fuzz testing, published benchmark corpus and registry dry-run/release validation.
