# AEP-0001: AER Enhancement Proposal Process

Status: Draft

## Purpose

AEPs provide a stable process for proposing changes that can affect interoperability.

## Required sections

- Problem statement
- Motivation
- Proposed design
- Syntax and examples
- Canonical-model impact
- Binary compatibility impact
- AI profile impact
- Security impact
- Alternatives considered
- Conformance vectors
- Migration strategy

## Decision rule

A proposal is accepted only when it has a clear compatibility story and testable conformance criteria. Performance claims must include reproducible benchmark methodology.
